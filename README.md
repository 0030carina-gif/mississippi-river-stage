# 密西西比河水位季节性

圣路易斯及开罗、孟菲斯、维克斯堡、巴吞鲁日、新奥尔良关键站的水位季节性对照，服务于美国谷物驳船运输观察。

用浏览器打开：[GitHub Pages](https://0030carina-gif.github.io/mississippi-river-stage/)（推荐），或查看仓库里的 [index.html](./index.html)。

## 本期

数据截至 2026-11-26（观测时间均为 Asia/Shanghai，UTC+8）。

整条河不是同一状态：开罗—孟菲斯—维克斯堡中下游季节性偏低；圣路易斯、巴吞鲁日、新奥尔良为季节性正常。开罗接近 NWS 低水阈值；圣路易斯当前仍高于 1.0 ft 减载参考，但 NWS 预报约 10 天后可能低于该水平。

## 数据

水位为各站水尺读数（stage），来自 USGS Water Data、NWS NWPS 与 USACE CWMS 公开接口。近期观测为临时数据，可能经修订。预报不是实测。

图与结论只放在 `index.html` 和两张 PNG 里，原始下载缓存不入库。
